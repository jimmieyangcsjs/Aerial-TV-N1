# Aerial TV N1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build and publish an N1-specific Aerial TV adaptation that shows the existing N1 Pocket Remote QR on Home and remains stable across boot and network changes.

**Architecture:** Keep Aerial's native desktop architecture. Keep Aerial and N1 Remote as separate APKs. Add a narrow, same-signature ContentProvider bridge in Aerial, render a non-focusable Home card, and rely on the existing Remote foreground service for control. Add package-based tile recipes for persistent N1 app icons.

**Tech Stack:** Kotlin, Jetpack Compose 1.9.x, Android API 25, ZXing, NanoHTTPD (upstream), JUnit 4, Robolectric.

**Spec:** `docs/superpowers/specs/2026-11-13-aerial-tv-n1-design.md`

## Global Constraints

- Package name remains `app.orchard.tv`.
- `minSdk = 21`; N1 target is Android 7.1 / API 25.
- All comments and identifiers are English; UI strings are added consistently to `values`, `values-zh`, `values-ru`, `values-uk`, and `values-kk`.
- Aerial must not install, download, or recommend N1 Remote.
- Aerial must not expose the N1 Remote PIN through its own HTTP server.
- Both APKs must use the same signing certificate.
- Do not merge Aerial with CleanYourTV-N1 or port code, layouts, visual components, or interactions from CleanYourTV-N1.
- No system application may be disabled or removed.
- Do not commit `local/`, device IPs, PINs, or serial numbers.
- Test release builds on the real N1; compilation alone is not acceptance.

```kotlin
fun read(context: Context): N1RemoteStatus? {
    val cursor = context.contentResolver.query(STATUS_URI, null, null, null, null) ?: return null
    return cursor.use {
        if (!it.moveToFirst()) return@use null
        N1RemoteStatusPolicy.parse(
            ip = it.getString(it.getColumnIndexOrThrow("ip")),
            port = it.getInt(it.getColumnIndexOrThrow("port")),
            pin = it.getString(it.getColumnIndexOrThrow("pin")),
            online = it.getInt(it.getColumnIndexOrThrow("serviceOnline")) != 0,
            url = it.getString(it.getColumnIndexOrThrow("url")),
        )
    }
}
```
